# Submission capture checklist

Screenshots have intentionally not been added yet. Capture them only after a CognoDB instance is
configured, seeded, and manually verified. Do not use hardcoded data to stage successful states.

Use a consistent desktop viewport and remove credentials, browser extensions, and personal data
from the frame. Add descriptive alt text when embedding each image in the root README.

- [ ] `landing-page.png` — value proposition, primary action, and graph-backed explanation.
- [ ] `planner-selection.png` — selected target role and several current skills.
- [ ] `planner-track-selection.png` — General vs specialization track selector and role-aware requirements.
- [ ] `analysis-result.png` — readiness score, matched skills, and missing-skill sections.
- [ ] `comparison-navigation.png` — similar-role card with shared skills and `Use as target` flow.
- [ ] `learning-roadmap.png` — at least one readable multi-step prerequisite path.
- [ ] `graph-explorer.png` — role, skill, and project nodes with the legend and details panel.
- [ ] `database-error-state.png` — honest unavailable/not-configured state with recovery guidance.

Also verify responsive layouts at approximately 375 px, 768 px, and 1440 px before submission.
